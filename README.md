# Zenix — Sign Up & Login

A polished, responsive authentication UI for **Zenix**, a premium watch house concept from Karachi. The project pairs an elegant dark interface with warm gold accents and a clean, accessible form experience.

> **Fine watches. Honest repair.**  
> Karachi's watch house since 1998.

## Preview

Open the project locally by downloading `index.html` and launching it in a modern browser.

## Features

- Combined **Sign Up** and **Login** views with animated switching
- Responsive two-panel layout for desktop, tablet, and mobile
- Zenix brand styling with dark emerald tones and refined gold accents
- Form fields for name, username, email, password, and password confirmation
- Password visibility controls and a visual password-strength meter
- Inline validation feedback and status notifications
- Keyboard focus styling and reduced-motion support
- Single-file setup — no build process or separate stylesheet required

## Built With

- HTML5
- CSS3
- React 18 (UMD)
- JavaScript (JSX compiled in the browser with Babel Standalone)

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Switch between the Sign Up and Login tabs to explore the interface.

The page loads React and Babel from public CDNs, so an internet connection is required when opening it.

## Important Note

This project is a **front-end UI demonstration**. The forms demonstrate interface interactions and client-side validation; they are not connected to a backend, database, or real authentication service. Do not enter real or sensitive passwords.
